# Project-Priority-Matrix

Data-Driven Project Prioritization: Impact vs. Feasibility Matrix Analysis

A strategic business intelligence project demonstrating core analytical and visualization skills. This repository contains the data, scoring methodology, and resulting visual matrix used to objectively prioritize key organizational projects.


Objective: To transition project selection from subjective decision-making to a data-driven process by balancing Business Impact against Organizational Effort/Feasibility.


Key Skills Demonstrated:

Strategic Modeling: Creation of a quantitative framework (Project Priority Matrix) for strategic planning and resource allocation. * Data Analysis: Scoring projects based on defined metrics (Impact, Feasibility, and Size/Cost). * Data Visualization: Generating a clear, four-quadrant bubble chart to communicate complex prioritization decisions (identifying Quick Wins, Major Projects, etc.).




Decision Support: Providing clear recommendations on project sequencing and resource focus.

Tool Stack:

Data Processing: (e.g., Python/Pandas or SQL for cleaning and scoring)

Visualization: (e.g., Power BI, Tableau, or Matplotlib/Seaborn)
